Политика конфиденциальности

Обработка персональных данных Наша клиника надлежащим образом управляет персональными данными пациентов и использует их только в следующих целях. 1. Цели использования персональных данных ・Управление медицинскими приёмами ・Связь по вопросам лечения ・Отправка писем с подтверждением бронирования ・Оказание медицинских услуг 2. Предоставление персональных данных третьим лицам Клиника не передаёт персональные данные третьим лицам без согласия пациента, за исключением случаев, предусмотренных законом. 3. Управление персональными данными Клиника принимает надлежащие меры безопасности для предотвращения утечки, утраты или повреждения персональных данных. 4. Раскрытие, исправление и удаление персональных данных Пациенты могут запросить раскрытие, исправление или удаление своих персональных данных. Обратитесь на стойку регистрации. 5. Запросы По вопросам обработки персональных данных обращайтесь на стойку регистрации клиники.
