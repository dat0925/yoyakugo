## 開き方

| 見たいもの | 開くファイル |
|---|---|
| 入口（3つの画面への案内） | `index.html` |
| 本部コンソール | `B画面(管理画面)/hq_index.html` |
| エリアマネージャーの表示 | 本部画面の上部「表示するユーザー」で切替／`B画面(管理画面)/hq_index.html?as=am` |
| 店舗画面（店舗切替つき） | 本部の「店舗別の比較」で店舗名を押す／`B画面(管理画面)/admin_index.html?store=s1001` |
| 店舗側の予約情報の共有 | 店舗画面の「受付・予約」で予約を開く（予約詳細の先頭に「グループ内の他店舗での予約・来店」が出る） |

ブラウザで直接開けば動く（ビルド不要）。

**閲覧にはPINコードが必要**（`pin_gate.js`。PINはハッシュで照合し、平文はソースに置いていない。PINは商品企画の担当者に確認する）。
一度通ればタブを閉じるまで再入力は不要。公開URL：https://dat0925.github.io/yoyakugo/multistore-proto/
