سياسة الخصوصية

معالجة المعلومات الشخصية تدير عيادتنا معلومات المرضى الشخصية بشكل مناسب وتستخدمها فقط للأغراض التالية. 1. غرض استخدام المعلومات الشخصية ・إدارة المواعيد الطبية ・التواصل بشأن العلاج ・إرسال رسائل تأكيد الحجز ・تقديم الخدمات الطبية 2. تقديم المعلومات الشخصية لأطراف ثالثة لن تقدم العيادة معلومات شخصية لأطراف ثالثة دون موافقة المريض، إلا إذا تطلب القانون ذلك. 3. إدارة المعلومات الشخصية ستتخذ العيادة تدابير أمنية مناسبة لمنع تسرب أو فقدان أو تلف المعلومات الشخصية. 4. الإفصاح والتصحيح والحذف يمكن للمرضى طلب الإفصاح أو التصحيح أو الحذف. يرجى الاتصال بمكتب الاستقبال. 5. الاستفسارات للاستفسارات عن معالجة المعلومات الشخصية، يرجى الاتصال بمكتب استقبال العيادة.
